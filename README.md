# EN VISIO

Jeu d'horreur à anomalies, dans une réunion visio. Si tout est normal, tu restes. Si quelque chose cloche, tu cliques sur « Quitter ».

**v0.6.0** — deux nouveaux modes en ligne : **Traître** (un joueur sabote la réunion en secret, démasquez-le) et **Entité nomade** (l'entité saute d'un joueur à l'autre, prévenez-le à temps).

## Télécharger

La dernière version se trouve dans les [releases](https://github.com/Flanix7/en-visio/releases/latest) :

- **Windows** : [EN_VISIO_Windows.zip](https://github.com/Flanix7/en-visio/releases/latest/download/EN_VISIO_Windows.zip) — dézippe le fichier dans un **nouveau dossier**, puis lance l'exécutable (garde le `.pck` et les `.dll` à côté).
- **Android** : [EN_VISIO_Android.apk](https://github.com/Flanix7/en-visio/releases/latest/download/EN_VISIO_Android.apk) — installe le fichier à la main (autorise l'installation depuis cette source, ce n'est pas encore sur le Play Store).

À partir de la v0.4.0, le jeu Windows peut se mettre à jour tout seul au lancement (il télécharge uniquement le contenu du jeu). La v0.6.0 reste compatible avec l'exécutable v0.4.0. Sur Android, le jeu affiche une alerte si une nouvelle version existe ; installe alors le nouvel APK.

## Le jeu

Deux chapitres (le premier au bureau, le second à l'hôpital Saint-Aubin), plusieurs fins, et un mode en ligne pour le chapitre 1.

Menu → « Jouer en ligne ». Un joueur crée une partie et donne le **code à 4 caractères** ; les autres le tapent pour rejoindre (2 à 4 joueurs, aussi entre un PC et un téléphone). Pas de compte à créer, pas de port à ouvrir (connexion via Epic Online Services).

Dans le salon, l'hôte choisit le mode :

- **Classique** : on repère les anomalies ensemble.
- **Élimination** : un faux pas (entité ou mauvais vote) t'élimine, les autres continuent.
- **Traître** (3 à 4 joueurs) : un joueur reçoit en secret des pouvoirs (brouiller un écran, frapper à une porte, fausse anomalie, vote truqué). Une accusation d'urgence par partie, un vote final, puis la révélation : « Le traître était… ».
- **Entité nomade** : à chaque réunion, l'entité saute sur un joueur. Sa webcam bugue chez les autres, qui peuvent le prévenir. Vies partagées, et elle va de plus en plus vite.

Tout le monde doit avoir la même version pour jouer ensemble.
