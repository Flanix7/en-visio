# EN VISIO

Jeu d'horreur à anomalies, dans une réunion visio. Si tout est normal, tu restes. Si quelque chose cloche, tu cliques sur « Quitter ».

## Télécharger

La dernière version Windows se trouve dans les [releases](https://github.com/Flanix7/en-visio/releases/latest) : dézippe `EN_VISIO_Windows_v3_2.zip` dans un **nouveau dossier**, puis lance `EN_VISIO_v032.exe`.

À partir de la v0.3.2, le jeu peut se mettre à jour tout seul au lancement (il télécharge uniquement le contenu du jeu).
